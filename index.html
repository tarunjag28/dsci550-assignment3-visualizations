City Bar Chart

This chart ranks cities by the number of haunted places. The data was cleaned and aggregated in Assignment 1, and this visualization makes it easy to compare haunting frequency across urban centers.

State Bar Chart

Similar to the city chart, this shows how haunted place counts vary by state. It helps identify which regions have the highest concentration of reported phenomena.

State Treemap

The treemap visualizes haunted places by state in a compact space, with area size proportional to the count. It provides a more intuitive representation of distribution than a bar chart when comparing many states.

Event Type Pie Chart

This chart shows the distribution of haunted event types (e.g., Supernatural, Murder). These categories were standardized during preprocessing, and the pie format offers a quick view of prevalence.

Time of Day Donut Chart

Based on cleaned timestamp data, this chart displays when ghost sightings typically occur (e.g., night vs. morning). It helps highlight temporal patterns in reported hauntings.
